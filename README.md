# 👤 Profile Card UI Design

A modern, elegant, and fully responsive **Profile Card** built using **HTML5** and **CSS3**. It features custom profile details, interactive social media buttons, engagement analytics counters, and a refined custom color gradient design.

🔗 **Live Preview:**https://pr0file-card-ui-design.netlify.app

---

## 🛠️ Built With / Technologies Used

* **HTML5** - Structuring the profile card elements, image container, social media links, and analytics sections.
* **CSS3** - Custom styling, Flexbox layout, linear gradients, box shadows, and smooth hover transition effects.
* **Google Fonts** - Styled using the "Poppins" typography for a clean and professional look.

---

## ✨ Key Features

* **Custom Color Theme:** Styled with an elegant custom gradient background on the header and interactive buttons.
* **Centered Layout:** Uses Flexbox to perfectly center the profile card on any screen size.
* **Interactive Social Links:** Styled circular buttons equipped with brand colors and hover effects for social media profiles.
* **Analytics Bar:** Clean bottom section displaying engagement counters (likes, messages, shares) with icons.
* **Action Buttons:** Fully styled "Subscribe" and "Message" buttons with smooth scale and background transitions.
